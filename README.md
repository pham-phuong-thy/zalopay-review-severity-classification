# ZaloPay Review Severity Classification

An NLP project for analyzing customer satisfaction from ZaloPay Google Play reviews using Vietnamese sentiment classification.

## 📊 Interactive Dashboard

Explore the interactive dashboard:

🔗 **Live Dashboard:**  
https://pham-phuong-thy.github.io/zalopay-review-severity-classification/dashboard/zalopay_dashboard.html

The dashboard provides:

- Customer satisfaction overview
- Rating distribution analysis
- Monthly review trend
- PhoBERT model performance evaluation
- Negative review root-cause analysis
- TF-IDF baseline vs PhoBERT comparison
